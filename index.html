    agents-cli¶

    agents-cli
    in Agent Platform

    Google Cloud 상에서 에이전트를 구축하기 위한 CLI 및 스킬입니다.

    시작하기 → GitHub에서 보기

    사용 중인 코딩 에이전트와 연동됩니다

    외 다수
    # CLI 및 스킬 설치
    $ uvx google-agents-cli setup
    # 이제 코딩 에이전트에 구축을 요청하세요
    > 인시던트를 분류하는 에이전트
